# FinPilot

安全智能的个人财务伙伴

[观看演示视频 · 4分44秒](https://github.com/JinchengGao-Infty/FinTechCompetition/blob/20a9d5f217d03e5e4a3f4e10144c6d33e9fe6165/video/FinPilot.mp4)

## 打开离线演示

需要 Python 3.12 或以上；主程序只用标准库，无需安装前端依赖。

```sh
git clone --branch 26fincom_v2 https://github.com/gr-peng/FinTechCompetition.git
cd FinTechCompetition
python -B server.py --port 65281
```

打开 [离线展示页](http://127.0.0.1:65281/showcase.html?session=offline-preview&offline=1#/bot)，点左侧示例填入，再点发送。后续在对话卡片中选择、核对和确认；每个场景前点左侧“重置演示”。离线密码卡会显示演示密码，无需模型 Key。

照着 [5个场景和15个常用问题](docs/DEMO-PROMPTS.zh-CN.md) 体验。离线支持预置示例和卡片操作；自由问答需切换在线模式并连接模型。

## 伙伴能做什么

- **先守住钱，再推进任务。** 结合收款记录、金额和风险证据分级，先确认、再验证；三次密码错误冻结十分钟，邮件里的指令不能变成付款授权。
- **有事主动提醒。** 房租邮件、会员到期和出发前一小时提醒进入对话，确认范围后才继续，未到时间不会报成已执行。
- **一句话安排多件事。** 给妈妈发短信、预约顺风车并设置提醒；离线还可体验餐厅、蛋糕、定金和生日定时转账，逐步确认、随时取消。
- **把模糊想法问清楚。** 从“手里有点钱，想理一理”开始，选择攒钱或收益方向，结合账户和账单安排预算、储蓄罐或理财方案。
- **文字与语音接续。** 单麦克风输入、独立语音连接、流式播报和数字读法；不连接语音也能完成文字与卡片操作。

财务页汇总账本、图表、预算、储蓄罐和卡片；投资页展示持仓、理财及研究资料。结果按执行记录生成，完成后的过程可以展开查看。

短信、预订和资金操作由本地适配器执行，不连接真实银行或商家。声纹按钮展示验证动画，不是真实生物识别。提醒需要 App 和本地服务保持运行；离线时间可由展示页推进。

## 在线使用与开发

启动和模型连接见 [运行指南](RUNNING.md)。支持 Micu 与 MiniMax 官方对话，模型名可编辑；MiniMax 语音独立连接。凭据只留在服务内存，由用户自行填写。

```text
backend/          对话协议、提供方连接、会话与后端适配
baseline_backend/ 账户、持仓和行情数据模块
web/              App、桌面展示与前端资源
demo/             合成业务数据
config/           配置示例
tests/            自动化检查
tools/            启动验证与发布检查工具
docs/             演示流程和使用说明
server.py         本地启动入口
```
