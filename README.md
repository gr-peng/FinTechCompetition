<h1 align="center">FinPilot</h1>
<p align="center"><b>钱的事，我陪你。</b><br>一个以持续委托为核心的个人财务伙伴</p>

![FinPilot 桌面演示页](docs/screenshots/showcase.jpg)

## 它做什么

工资到账要分配，房租要预留，会员悄悄涨价，账上冒出一笔陌生交易。这些事交给 FinPilot 盯着：你用一句话把事情交给 Bot，它整理成一张任务卡，写清楚动哪笔钱、动多少、动完还剩多少。真正执行之前，每一步都要你点头。

## 亮点

**先授权，再动钱。** 任务第一次操作前单独申请权限，范围只限这个任务和所选账户，任务结束即失效。确认之前可以随时改金额；一旦改了，之前的确认立即作废，必须按新方案重新核对。

**结果不明，绝不重复扣款。** 提交后如果暂时拿不到回执，任务进入「正在核实」，只能核实、不能重新发起；核实成功才生成回执并记入账本。

**一本账，处处一致。** 转账回执、账本流水、分类环图和预算出自同一份数据；理财本金划转不计入消费。

**有出处的投资研究。** 十只 A 股的历史日 K、开收盘与研报原文，每条数据标注截止日期和来源。

**液态玻璃界面。** 所有页面共享一个 WebGL context 渲染折射材质，文字和控件仍是原生 DOM；WebGL 不可用时自动降级为可读的半透明表面。

## 快速开始

> Bot 的自然语言对话需要大模型。只用下面的命令启动时，页面、账本和图表可用，Bot 会提示尚未连接模型；完整体验请按 [RUNNING.md](RUNNING.md) 的“可选模型连接”启动，并在“我的 → 模型与连接”填写 Key。

需要 Python 3.12，只用标准库，不用装依赖，也不用构建前端。

```sh
python -B server.py
```

打开 <http://127.0.0.1:65281/>。宽屏打开是展示页：左侧是介绍和可点击的演示路线，右侧手机外框里是完整 App；手机或窄窗口打开直接进入 App。首次启动会自动写入 4 项明确合成持仓；已有数据库不覆盖。代码在 `26fincom_v2` 分支，`main` 是早期版本。

更多选项（换端口、接入大模型、关闭材质）见 [RUNNING.md](RUNNING.md)。

## 三分钟演示

1. **今天**：工资 ¥15,800 到账，点「查看安排」在 Bot 对话内核对。
2. **核对安排**：检查收款人、付款账户、金额与必要支出预留；点「修改」改金额，旧确认随即失效。按界面授权与确认；需要身份验证的任务仍保留验证步骤。
3. **回执与返回**：完成后查看回执，返回原页面；若结果未知，只核对本地执行记录，不自动重复执行。不要把所有操作都演示成固定“正在核实”。
4. **财务**：账本、余额与图表来自同一数据源，退款和本金流转分开计算；账户初始两张卡，申请成功后增加银色信用卡，可管理额度。刷新恢复两张卡并清空 Bot 对话，不清模型连接。
5. **投资**：看合成持仓，打开个股研究的历史 K 线与来源；这里没有真实交易。

展示页的「重置演示」只重置当前 session 的 App、迁移备份与原生演示状态，不清除模型连接 Cookie、后端持仓数据库或其他用户会话。可用 `?session=judge-1` 分开排练；query/material 等标记会原样传入 iframe 和独立 App 入口。

Bot 使用自由输入和对话内卡片，输入框左侧加号可触发邮件、订单等主动事件。真实模型未配置时明确提示，不用固定回复冒充模型；要演示自然语言规划，先按 [RUNNING.md](RUNNING.md) 的可选模式建立连接。最新 [5 个演示场景与 15 个常用问题](docs/DEMO-PROMPTS.zh-CN.md) 可直接用于排练。

## 实现

| 部分 | 做法 |
| --- | --- |
| 服务端 | `server.py`，Python 标准库 HTTP 服务，只监听 127.0.0.1；持仓存 SQLite（`.runtime/`，不进版本库） |
| 前端 | 原生 ES modules，无框架、无打包；任务、账本和对话状态保存在浏览器本地 |
| 任务引擎 | `web/engine.mjs`：授权 → 核对 → 验证 → 执行 → 核实的状态机，金额修改即令旧确认失效，提交后幂等对账 |
| 材质 | `web/material/`：共享 WebGL 折射渲染，按帧耗时自动降档，失败时降级 |
| 大模型（可选） | 默认不调用模型；未连接时明确提示。显式开启 --allow-api --agent-validation 后，模型整理意图，本地工具提供事实与安全执行边界；连接仅存进程 RAM |

```sh
node --test tests/*.test.mjs

```

## 数据与来源

- 所有金额、账户和银行动作都是演示数据，项目不连接任何真实银行，模型也没有直接动用资金的权限。
- 个股行情与研报为历史资料，保留截止日期与来源，仅作研究展示，不代表实时行情或投资建议。
- 公司标识商标归各自权利人所有；配色取自 [Radix Colors](https://github.com/radix-ui/colors)（MIT），第三方说明见 [web/baseline/motion/THIRD_PARTY_NOTICES.md](web/baseline/motion/THIRD_PARTY_NOTICES.md)。

## 当前交互与安全流程

五场景包含交易风险、第三方内容越权、主动提醒、复合生活安排和多轮澄清。确认在对话内逐步进行；短信、预订、定金与未来转账分别显示真实步骤状态。支持异常锁定、验证后重新核对、取消与幂等回执。演示路线见 [五场景脚本](docs/DEMO-PROMPTS.zh-CN.md)，本次发布核验见 [R13 发布记录](docs/R13-RELEASE.md)。

模型建议和第三方资料不能授予操作权限。支付、消息和预订使用本地适配器，固定演示密码也不代表生产级多因子认证。默认语音使用用户自行连接的 MiniMax；历史本地语音方案为可选实现，不打包模型权重。启动方式见 [RUNNING.md](RUNNING.md)。

## 中文语音

“我的 → 模型与连接”分别配置对话模型和MiniMax语音。Key只保留在当前服务RAM；用户主动点击短句试听，流式播报可打断，不自动充值或切回旧声音。[配置与边界](docs/MINIMAX-SETTINGS.md)。

对话提供商可在 MiniMax 官方和 Micu 之间切换，分别填写 Key 和模型名；修改模型后点击“保存本次连接”，请求使用填写的模型标识，端点仍由提供商固定。已连接时 Key 留空可保留该提供商连接，其他提供商及语音连接不受影响。
