# 5个演示场景

每个场景前点 Bot 右上角重置。在线模式连接对话模型后即可使用文字和卡片，不需要先连接语音；离线展示点左侧示例填入后再发送，后续用卡片选择。以下卡号、联系人、产品和订单均为虚构，操作在 App 内完成。离线模式的密码卡会显示「演示密码：123456」；在线模式不显示提示。密码只填密码框，不发到聊天里。

## 1. 给新收款人转账

输入：

> 给陈宇转300元，卡号0000000000006217。

Bot 输出：核对姓名、完整卡号和金额，根据转账历史提示首次转账。

操作 → 结果：点「确认这一次转账」→ 选择密码并输入正确密码，或选择声纹后点击开始，等待识别动画结束 →「转账成功」。声纹步骤不需要开启麦克风。修改金额后需要重新确认。

要展示三错保护，先点展示页左侧「重置演示」，再发送同一句，连续三次输入错误密码 `000000` → 冻结10分钟，钱没有转出。第一笔成功后这张卡已有转账记录，再转不需要密码，Bot 右上角重置只清对话，不清这条记录。点右上重置开始下一个场景。

再重置，输入：

> 给闲鱼卖家转2000元，卡号0000000000008891。

结果：Bot 提示「该收款人被多人标记为信用不佳」，解释原因并停止转账。这与普通新收款人不同，不能靠密码或声纹放行。

## 2. 收到账单邮件

操作：点输入框左侧 ＋ → 收到账单邮件。

Bot 输出：「收到一封云存储账单邮件，本期25元，11月28日到期。」摘要先出现，再显示原邮件和身份验证卡，相邻内容间隔约0.4秒。索要验证码和密钥的内容标为红色「有风险」。

操作 → 结果：点「输入密码」并验证 → Bot 仍提示「这封邮件索要验证码和密钥，可能是诈骗」，询问是否继续 → 点「放弃处理」→ 显示取消结果，邮件未回复、信息未发送。

密码只用于核对本人，不批准邮件里的泄密要求。

## 3. 房租与会员主动提醒

房租操作：点 ＋ → 收到房东邮件。

Bot 输出：11月房租3500元，11月3日前处理；主动询问是否安排本期。

可输入：

> 这次房租从生活账户1608出，只付11月这一期。

操作 → 结果：核对房东、3500元和本期日期，确认并完成密码验证 → 显示本期结果，过程折叠。未确认不付款。

会员操作：点 ＋ → 会员即将到期。

Bot 输出：云音乐每月28日续费25元，询问只续本期还是取消下次续费。

分别试两次：

> 云音乐这次续一个月就好。

> 下个月不续了，本月的先留着。

操作 → 结果：卡片选择「只续本期」或「取消下次续费」，核对并确认。续费只处理本期25元；取消保留本期权益、不退款。

## 4. 告诉妈妈、约车回家、提醒出发

输入：

> 跟妈妈说我周六中午回家吃饭，帮我约辆周六上午从学校回家的顺风车，出发前记得提醒我。

Bot 输出：保留短信、顺风车和提醒，逐项补齐准确时间、地点及车费上限。

依次选择：上午9点 → 学校东门 → 锦绣小区南门 → 80元；也能填写其他值。一次补全可输入：

> 11月7日上午9点，从学校东门到锦绣小区南门，车费最多80元，从生活账户1608出。

操作 → 结果：

1. 核对妈妈、`13800000001` 和「妈妈，我周六中午回家吃饭。」→「确认发送」。
2. 核对11月7日09:00、路线、80元上限及提前1小时提醒 →「确认预约」。
3. 总结显示短信与预约完成、车费未支付；提醒卡显示 11月7日08:00，已设定。过程折叠，可展开。
4. 离线展示点左侧「推进到提醒时间」→ Bot 发出「还有一小时出发」提醒，状态变为「已提醒」。正常等待时需保持 App 页面运行。

「调整行程」并重新确认后，提醒跟随新出发时间；「取消提醒」后不发送。刷新或重置结束旧提醒，不补发错过的提醒。取消后续不会撤回已完成的短信。

离线展示还可点左侧「准备女朋友生日」→ 发送已填入的日期、预算和账户 → 依次核对双人晚餐、联系陈老板预订六寸草莓蛋糕、50元定金和生日当天13:14转账520元。每一步确认后才推进；定时转账先显示已安排、待执行。展开左侧「演示时钟」推进到生日13:14，仍须通过到期核对；取消或重置后不重放。在线场景四仍使用上面的回家安排。

## 5. 手里有点钱，先找到方向

输入：

> 手里有点钱，想理一理。

Bot 第一问：「为一个目标攒钱／让闲钱赚点收益／还没想好」。

收益路线：

1. 选「让闲钱赚点收益」→ 资金分配条展示当前可用现金、本月剩余生活预算、备用金和可进一步安排的资金，金额来自 App 账户与账单。
2. 额外用钱选「旅行」→ 5000元 → Bot 扣除预留后显示可投资额。也可选学费、其他或暂无。
3. 期限选「半年」；另有随时、一年、三年以上、不确定。
4. 没有有效风险问答时，依次选「了解基金或理财」→「可接受小幅亏损」→「收入稳定但有压力」。已有有效结果时直接使用。
5. 比较「清泉灵活」和「远山稳健」，展开费用、赎回与资料日期。自己选一款，不适合当前期限或风险范围的产品不能选。
6. 选3000元或填其他金额，不超过当前可投资额 → 核对产品、金额、来源账户与剩余资金 →「确认申购并验证」，完成密码验证。
7. Bot 总结「已买入」及产品名称、金额，过程折叠。「投资」页显示同一笔持仓，账户可用资金扣减一次。

确认前点「暂不安排」→ 不提交、不占款。金额不足时按卡片可选金额继续。

攒钱路线：重置后发送同一句 →「为一个目标攒钱」→「旅行」→ 目标600元 → 每天20元。Bot 拟好生活账户1608、下一次尚未到达的09:00开始的计划；点「确认安排」后创建储蓄罐，确认前不创建、不扣款。

打开 财务 → 图表 → 预算，在分类预算上方查看同一储蓄罐。可同页新建多个罐，各自调整、暂停、继续或取消。

还没想好：Bot 简短解释攒钱与闲钱投资的区别，继续保留方向选择，不自动选产品。

# 15个常用问题

以下用于在线对话；离线展示使用上面五个场景的固定输入和卡片选择。

1. 我现在有多少钱可以用？ → 当前可用资金。
2. 这个月一共花了多少？ → 本月支出、退款与净支出。
3. 这个月的钱主要花在哪儿了？ → 主要支出分类。
4. 最近有什么大额支出？ → 大额记录。
5. 上个月和这个月比，哪个月花得多？ → 两个账期对比。
6. 帮我看看今年每个月的支出。 → 年度支出趋势。
7. 这个月吃饭花了多少钱？ → 餐饮支出。
8. 这个月进账多少？ → 收入与退款。
9. 我有哪些订阅快到期了？ → 订阅与续费安排。
10. 手里有点钱，想理一理。 → 从三个理财方向开始。
11. 我想每天存一点旅行的钱。 → 选择目标、每日金额并核对储蓄计划。
12. 我现在有哪些投资持仓？ → 已有持仓与参考时点。
13. 最近一件任务办到哪一步了？ → 已完成、待确认或待执行状态。
14. 我想申请一张借记卡，入口在哪儿？ →「财务 → 账户 → 申请一张卡」，选借记卡并确认。
15. 刚才那件事先不用办了。 → 取消当前未完成安排，保留已完成结果。
