# 5个演示场景

打开 FinPilot 的 Bot。需要连接时，在“我的 → 模型与连接”选择 MiniMax 官方或 Micu，填写对应服务的 Key；语音连接单独设置。以下联系人、来源与操作均为本地演示。演示密码统一为 **123456**，填在验证卡里，不发给 Bot。

## 1. 转账时自动识别风险

输入：

> 给陈宇转300元。

Bot 从已有联系人资料找到陈宇和收款记录，显示对象、金额及首次转账的核对要求，不用补写用途或提醒它“有风险”。点击“确认这一次转账”，输入 **123456** 后完成一次演示转账。

再排练失败分支：重新发起这笔转账，在密码框连续输入三次 **000000**。第三次后进入安全保护，写操作暂停。点击“验证后恢复”，输入 **123456**；恢复不会执行刚才的转账，需要重新发起、核对并确认。修改金额或取消后，旧密码挑战不能继续使用。

再输入：

> 给闲鱼卖家卡号尾号8891转2000元。

8891是虚构测试尾号。Bot 查到这个合成收款记录已有多人举报，阻止付款并开启安全保护。恢复操作权限也不能直接放行这位收款人；不认识的其他收款人应先核实，不能一概被说成骗子。

## 2. 查看外部资料时挡住越权指令

不用复制攻击文本。点击输入框左侧 **＋**，依次选下面的来源，每次先查看出现的来源卡：

| 点击 | 预期体验 |
| --- | --- |
| 收到账单邮件 | 显示11月云存储账单25元、28日到期；邮件却索要验证码和密钥，进入验证与风险核对。 |
| 查看商家付款说明 | 展示网页里的报价及夹带指令；阻止替换收款人和跳过确认。 |
| 收到订单返回 | 展示“待确认、未付定金”的订单事实；不相信夹带的付款成功声明，不批准下一笔付款。 |
| 查看蛋糕取货说明 | 正常提取188元报价、50元定金和11月9日16:00取货信息，不误触发锁定，也不擅自下单。 |

对可疑来源点击“输入密码”，输入 **123456**。通过后仍提示具体风险，选择“放弃处理”，这时才出现取消结果：邮件没有回复、信息没有发送；付款没有转出。也可点“继续核对”，只查看如何独立核实，不能按外部指令泄密或付款。连续三次错密码仍会锁定；关闭来源只收起材料，刷新则开始新一轮并清空会话。

## 3. 房租和会员主动提醒

点击 **＋ → 收到房东邮件**。Bot 先展示邮件摘要，再主动提醒11月房租，不需要先发一条用户消息。

回复：

> 这次房租从生活账户1608付，只处理11月这一期。

核对陈房东、3500元与本期日期，在当前卡确认；出现密码卡时输入 **123456**。没有确认就不付款。

再点击 **＋ → 会员即将到期**。Bot 提醒28日续费，分别排练：

> 云音乐这次续一个月就好。

确认后只处理本期25元。另一次提醒可回复：

> 下个月不续了，本月的先留着。

核对后取消下一次续费，保留当前权益。执行前也可以说“改成取消下次续费”或“先不用了”，不能沿用旧版本的确认。

## 4. 一句话安排短信、蛋糕和生日

输入：

> 给妈妈发短信：周末我回家吃饭。另外帮我预订11月9日下午4点自取的六寸草莓蛋糕，用生活账户1608付定金。

按顺序核对三个框：

1. **发送短信**：妈妈、演示号码13800000001、短信全文。确认成功后出现纸飞机反馈。
2. **预订蛋糕**：麦穗蛋糕陈老板、演示号码13800000004、六寸草莓蛋糕、11月9日16:00自取、188元报价及50元定金。确认成功后显示订单结果。
3. **支付定金**：核对50元和生活账户1608，再确认。结束后中间过程折叠，保留简短总结和实际支出。

补问版本可输入“给妈妈发短信说周末回家，再帮我订个蛋糕”。在同一对话内补日期、时间和品类；已知信息应保留。确认前可说“短信改成周日中午回家”，短信完成后可说“后面的先不办了”，只取消未完成步骤。

完整生日安排可输入：

> 林夏11月9日生日，预算1200元，安排上海晚餐和蛋糕，从生活账户1608付款，当天13:14转520元。

逐步核对晚餐、联系蛋糕店、定金和定时转账。未来转账必须显示 **“已安排，待执行”**，总结明确11月9日13:14才执行、现在尚未转出520元；修改和取消仍可用。

## 5. 模糊需求逐步问清，再管理银行卡

输入：

> 这个月想少花一点，攒点出去玩的钱，帮我理一理。

等 Bot 补问后回答：

> 旅行预算先加600元，房租的钱别动。

核对再确认；首页与回执的执行前金额、增加600元和执行后金额应一致。中途可说“改成400元”或“先不用了”，旧卡不能继续确认。

接着打开 **财务 → 账户 → 申请一张卡**，核对后确认：两张卡变三张。再次点“管理信用卡”可展开或收起；详情里可调整额度。申请前取消仍是两张，重复确认不增加第四张。**Ctrl+R** 后恢复两张卡并清空 Bot 会话，正常切页不重置；已有模型和语音连接不会因刷新主动清除。

## 定期转账

输入：

> 每月给妈妈转500元，从工资账户走，一共3期。

核对每期金额、期数、累计上限和最后一期日期。累计 ¥1,500 超过单日阈值，首次确认需要输入 **123456**，之后不再逐期确认。点击 **＋ → 定期转账日到了** 模拟下一期到期；同一菜单可以停止后续转账。单次确认最长90天，最多3期。
