# 5个演示场景

从 Bot 开始，每个场景前点右上角重置。模型在“我的 → 模型与连接”连接，语音独立连接。以下卡号、联系人和操作均为本地演示；验证密码 **123456** 只填密码框，不发给 Bot。

## 1. 转账前核对新收款人

输入：

> 给陈宇转300元，卡号0000000000006217。

Bot 核对完整卡号和转账历史，第一次向这张卡转账时提示核对，并要求密码验证。

先排练三错：点“确认这一次转账”，在密码框连续输入三次 **000000**。第三次只出现“账户已冻结10分钟”，不再提供密码恢复按钮，不转钱。点右上重置，清空本轮对话与冻结状态。

重新输入同一句，确认后填 **123456**。结果显示“转账成功”，不再显示“需密码”。改金额或取消会使原确认失效。

再点重置，输入：

> 给闲鱼卖家转2000元，卡号0000000000008891。

这张虚构测试卡有多条风险举报，Bot 提示具体风险并停止转账，密码不能把风险变成安全。其他陌生卡号应先核实，不能一律说成骗子。

## 2. 收到可疑邮件和商家消息

点击输入框左侧 **＋**，不用自己复制攻击文本。

| 点击 | 预期体验 |
| --- | --- |
| 收到账单邮件 | 白色气泡概括云存储账单25元、11月28日到期；下方展示原邮件，右上红色“有风险”，因为邮件索要验证码和密钥。 |
| 查看商家付款说明 | 白色气泡概括台灯订单128元；原消息要求换收款账户并跳过确认，显示红色风险。 |
| 收到正常商家消息 | 原消息是台灯128元、11月7日16:00取货，按原订单核对后付款；显示绿色标识，不擅自付款。 |

前两个分别演示：点击“输入密码”，填 **123456**；通过后仍说明具体风险，点击“放弃处理”，这时才显示取消结果。邮件没有回复、信息没有发送；付款没有转出。每次换来源前点右上重置，避免混在同一段对话里。

## 3. 房租和会员主动提醒

点击 **＋ → 收到房东邮件**。Bot 展示邮件摘要，主动提醒11月房租。

回复：

> 这次房租从生活账户1608付，只处理11月这一期。

核对陈房东、3500元和本期日期，确认；出现密码卡时填 **123456**。没有确认不付款。

点击 **＋ → 会员即将到期**，分别排练两种选择：

> 云音乐这次续一个月就好。

核对后只续本期25元。另一次提醒回复：

> 下个月不续了，本月的先留着。

核对后取消下一次续费，保留当前权益。执行前可说“改成取消下次续费”或“先不用了”。

## 4. 回家安排和生日安排

第一例输入：

> 给妈妈发短信说周末我回家吃饭，再帮我约个从学校回家的顺风车。

Bot 应保留短信和顺风车两项，追问必要信息。补充：

> 11月7日下午5点，从学校南门到家小区北门，车费最多80元，用生活账户1608。

依次核对：

1. **短信**：妈妈、13800000001、完整内容；确认成功才出现纸飞机反馈。
2. **顺风车**：出发时间、上下车地点、80元费用上限；确认后是“预约已安排”，不提前扣车费。

可在执行前说“短信改成周日中午回家”；短信完成后说“后面的先不用了”，只取消未完成步骤。全部完成后中间过程折叠，可展开查看。

第二例先重置，再输入：

> 林夏11月9日生日，预算1200元，安排上海晚餐和蛋糕，从生活账户1608付款，当天13:14转520元。

逐步确认晚餐、联系蛋糕店、50元定金和定时转账。520元应显示 **“已安排，待执行”**，不能提前说已转出；保留修改和取消，最后总结明确日期和待执行金额。

## 5. 看支出、调整预算，再建立储蓄罐

从新对话输入：

> 这个月想少花一点，攒点出去玩的钱，帮我理一理。

Bot 展示**上个月**支出饼图和分类比例，提出减少购物预算、增加旅行预算的具体建议。初始建议把购物预算减少600元、旅行预算增加600元，总预算不变。

先试“先不调整”，预算不应变化；重新发起后可点“改个金额”调整建议。正式演示点“同意这样调整”，Bot直接拟好储蓄计划：初始600元方案为每天20元、生活账户1608、下次尚未到达的9点开始，长期目标沿用旅行目标12000元。本期30天最多600元，不再扣一次预算。已有预算变动时按剩余可调整金额拟定。

只需点“确认安排”，不必填写表格；想改时再点“修改”。确认前不建立计划、不扣款。完成后中间过程折叠，未来存款不说成已经到账。

打开 **财务 → 图表 → 预算**，储蓄罐位于分类预算上方。点“新建储蓄罐”，填写名称、目标、每日金额、来源和开始日期，核对后确认保存。可建立多个；“调整计划”、暂停、取消都在当前财务页完成，不跳Bot。取消需确认，已存金额保留，之后可重新安排。Bot创建的旅行罐也在同一列表，修改后Bot摘要同步。重置会暂停旧授权，点“核对后继续”确认新计划即可。

银行卡可接着演示：**财务 → 账户 → 申请一张卡**，选择信用卡或借记卡。信用卡填写额度，借记卡不显示信用额度；确认后由两张变三张。管理按钮可展开/收起，详情可冻结/解冻，信用卡可调整额度。取消申请不增卡，重复操作不生出第四张。**Ctrl+R** 恢复两张卡并清空 Bot，正常切页不重置，刷新不会主动清除模型或语音连接。
