# 在线离线体验

[打开评委体验页](https://finpilot-judge-demo.pgr17398956318.chatgpt.site)

左侧选择示例，填入右侧手机后发送。后续直接在对话卡片中核对和确认；每个场景开始前点“重置演示”。无需配置模型或语音 Key。

网页保留离线展示的背景、讲解区、手机外壳与业务交互。为适配静态托管，Python 的会话、合成持仓和事件接口由浏览器内适配器替代；并非把原 Python 服务直接部署到 Sites。每个标签页使用独立随机命名空间，刷新恢复既定演示初始态。所有付款、短信、预订和申购均为本地状态变化，不访问真实账户或商家。示例理解使用预设协议，不能替代在线自由问答。关闭页面后不会继续调度提醒。

## 导出静态目录

在仓库根目录运行：

```sh
python -B tools/build_judge_site.py --output dist-judge
python -m http.server 65282 --bind 127.0.0.1 --directory dist-judge
```

打开 `http://127.0.0.1:65282/`。导出器不覆盖已存在目录，不读取运行数据库、环境文件或凭据，也不修改 `web/`。保留输出内所有相对路径和第三方许可证。

可将导出目录托管在支持 ES Modules 的 HTTPS 静态服务。公网 HTTPS 是原前端安全上下文 API 的运行前提。不要把正式版本模型连接或私有数据库加入静态目录。

## 显示与回退

手机继续使用原来的适应窗口比例；支持 CSS zoom 的浏览器采用布局缩放，避免先栅格化整部手机后再缩小文字。玻璃背景仍保留，旧浏览器保留原缩放回退。

现有 Sites 的版本历史保留上一版本，可在 Sites 中部署该历史版本回退；GitHub 发布前也保留了独立 rollback 分支。停止本地静态服务不影响正常 App。
